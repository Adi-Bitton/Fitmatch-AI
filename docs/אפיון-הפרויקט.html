1. סקירה כללית

FITMATCH AI היא פלטפורמת התאמה מבוססת AI שמחברת מתאמנים לאנשי מקצוע (מאמנים אישיים, סטודיו, קבוצות ותזונאים) על סמך שאלון אפיון אישי לכל תחום. המייסד: בר אטיאס — לוחם ומפקד לשעבר בחטיבת גבעתי, מתחרה באיירון מן.

הפרויקט בגרסה הנוכחית הוא עיצוב מחדש מלא של הפרונט-אנד: התוכן והמבנה של האתר המקורי נשמרו, והחזות נבנתה מחדש כמערכת מותג פרימיום (סגול/ליים על רקע גרפיט סגלגל), רספונסיבית למובייל ולדסקטופ.

6. RaceScene — סצנת הגלילה של האיירון מן

app/components/RaceScene.tsx (Client Component).

הרעיון

אנימציית מסע: מקו הזינוק ועד השגת המטרות, דרך שלבי הטריאתלון (זינוק → שחייה → רכיבה → ריצה → סיום). התוכן מגיע מסרטון שהמייסדת יצרה ב-AI (5 סטילס → סרטון). מתוכו חולצו 153 פריימים ליחס 16:9, עם עוגן חיתוך אנכי שונה לכל שלב (כדי שהמתחרה יישאר בפריים למרות שהמקור ריבועי). הפריימים: public/race/frames/frame_001..153.webp (WebP, ~4.5MB בסך הכל).

מנגנון טכני

  • הסקשן גבוה (h-[210vh] מובייל / h-[420vh] דסקטופ).
  • בתוכו <canvas> דביק (sticky).
  • מיקום הגלילה (0–1) בוחר את הפריים ומצייר אותו על ה-canvas (cover-fit עם הטיה קלה כלפי מעלה).
  • כל הפריימים נטענים מראש; פס טעינה קצר עד שהשלב הראשון מוכן; fallback לפריים הקרוב שכבר נטען — למניעת הבהוב.
  • prefers-reduced-motion / ללא JS → תמונת סיום סטטית + כותרת.

תצוגה

  • דסקטופ: וידאו במסך מלא (full-bleed) עם כותרת, כיתוב לכל שלב ופס התקדמות — כשכבות overlay.
  • מובייל: מלבן ברוחב מלא (edge-to-edge) ביחס 3:2. הכותרת מעליו, הכיתוב ופס ההתקדמות מתחתיו (לא overlay).

כותרת

"מלווים אותך מקו הזינוק ועד השגת המטרות שלך" — המילים "קו הזינוק" ו-"המטרות שלך" בצבע אדום (#ff4d4f, מתכתב עם האדום של IRONMAN). בדסקטופ הכותרת בשורה אחת (whitespace-nowrap), במובייל נגללת.

פס ההתקדמות

פס דק עם נקודה נעה בגרדיאנט סגול→ליים. הכיתובים זינוק/שחייה/רכיבה/ ריצה/סיום מתחת לפס הוסרו לבקשת המייסדת (הפס והנקודה נשארו).

7. נגישות

מה נעשה בקוד

  • קישור "דלג לתוכן הראשי" בראש כל עמוד (layout.tsx, מופיע ב-focus).
  • מסגרת פוקוס גלויה (:focus-visible) לכל רכיב אינטראקטיבי.
  • aria-label לשדות טופס יצירת הקשר ולכפתור הוואטסאפ הצף.
  • העלאת ניגודיות הצבעים של --muted ו---faint.
  • כיבוד prefers-reduced-motion (אנימציות + סצנת הגלילה).
  • מבנה עמוד סמנטי, alt לתמונות, lang="he" dir="rtl".

עמוד הצהרת נגישות

/accessibility — הצהרה בעברית (רמת WCAG 2.1 AA / ת"י 5568 ככל שניתן, מגבלות ידועות, פרטי פנייה). מקושר מהפוטר.

ווידג'ט נגישות

מחובר בקוד ב-layout.tsx (UserWay, דרך next/script, lazyOnload). רנדר רק אם משתנה הסביבה NEXT_PUBLIC_USERWAY_ACCOUNT מוגדר — כרגע לא מוגדר, אז הווידג'ט כבוי. להפעלה: הרשמה ב-userway.org, העתקת Account ID, והגדרתו כמשתנה סביבה ב-Vercel (Production + Preview). ניתן להחליף ב-EqualWeb/נגישות ע"י שינוי ה-script.

מה שנותר (מחוץ לקוד)

9. פריסה, Git ודומיין

תהליך

  • כל העבודה על ענף redesign/premium-brand, נדחף ל-GitHub.
  • Vercel מחובר למאגר ובונה אוטומטית לכל push.
  • הדומיין www.fitmatch-ai.com מקושר לסביבת ה-Production של הפרויקט.

נקודה פתוחה קריטית

ה-Production Branch ב-Vercel עדיין מוגדר כ-master (האתר הישן). לכן push-ים לענף redesign/premium-brand יוצרים Preview בלבד ולא מתעדכנים אוטומטית בדומיין. עד עכשיו העלאות לפרודקשן נעשו ידנית ("Promote to Production"), ולכן חלק מהקומיטים האחרונים (נגישות, הסרת הכיתוב, תיקון הבורר, Analytics) טרם עלו לאתר החי.

התיקון (חד-פעמי): Vercel → הפרויקט → Settings → Git → Production Branch → לשנות ל-redesign/premium-brand → Save. הדומיין נשאר מקושר; מאותו רגע כל push עולה אוטומטית לאתר החי. (לחלופין: למזג redesign/premium-brand → master.)
