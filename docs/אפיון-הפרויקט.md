## 1. סקירה כללית

FITMATCH AI היא פלטפורמת התאמה מבוססת AI שמחברת מתאמנים לאנשי מקצוע
(מאמנים אישיים, סטודיו, קבוצות ותזונאים) על סמך שאלון אפיון אישי לכל תחום.
המייסד: בר אטיאס — לוחם ומפקד לשעבר בחטיבת גבעתי, מתחרה באיירון מן.

הפרויקט בגרסה הנוכחית הוא **עיצוב מחדש מלא של הפרונט-אנד**: התוכן והמבנה
של האתר המקורי נשמרו, והחזות נבנתה מחדש כמערכת מותג פרימיום (סגול/ליים
על רקע גרפיט סגלגל), רספונסיבית למובייל ולדסקטופ.

### סטאק טכנולוגי

| רכיב | גרסה / פרטים |
|---|---|
| Next.js | 16.2.12 (App Router, Turbopack) |
| React | 19.2.4 |
| TypeScript | מלא, `strict` |
| Tailwind CSS | v4 (`@import "tailwindcss"`, `@theme inline`) |
| גופנים | `next/font/google` — Heebo (עברית+לטינית), Space Grotesk (וורדמארק/לטינית) |
| אייקונים | `lucide-react`, `react-icons` (FaWhatsapp / FaInstagram) |
| אנליטיקס | `@vercel/analytics` |
| אירוח | Vercel (פריסה אוטומטית מ-GitHub) |
| שפה/כיווניות | `<html lang="he" dir="rtl">` |

### הערה חשובה על הגיבוי

### מחלקות עזר עיקריות

- `.kicker` — כותרת-על קטנה עם קו לפני (Space Grotesk, letter-spacing רחב)
- `.card` — כרטיס עם גבול, גרדיאנט עדין ורקע surface, פינות 1.25rem
- `.panel` — קופסה גדולה עם גרדיאנט וגבול, פינות 1.75rem
- `.glow` — הילה רדיאלית שדועכת ל-alpha 0 לפני הקצה (ללא "מלבן" נראה)
- `.cta-primary` — כפתור ראשי עם גרדיאנט סגול והילה
- `.bg-grid` — מרקם רקע דק מאוד עם דעיכה הדרגתית
- `:focus-visible` — מסגרת פוקוס סגולה גלויה לכל רכיב אינטראקטיבי (נגישות)
- מדיה `prefers-reduced-motion` — מבטלת אנימציות ומעברים

`py-7` (מובייל) · `sm:py-9` (טאבלט) · `lg:py-14` (דסקטופ) — כ-56px/72px/112px.

## 4. פירוט הסקשנים (לפי סדר בעמוד)

`page.tsx` מרכיב: Header → Hero → RaceScene → Benefits → About →
Categories → HowItWorks → Article → Founder → Trainers → FinalCta →
Contact → Footer → FloatingWhatsApp.
`<main dir="rtl" className="overflow-x-clip">`.

### 4.1 Header
כותרת דביקה. שקופה בראש העמוד; בגלילה מקבלת רקע `bg-ink/80` עם
`backdrop-blur`. ניווט דסקטופ מ-`NAV_LINKS`. במובייל — כפתור המבורגר
שפותח פאנל נשלף מימין (עם גלילה פנימית) שמכיל את הניווט + **רשימת
6 תחומי ההתאמה** (במקום dropdown בתוך dropdown). בדסקטופ כפתור
"התחילו עכשיו" הוא בורר תחומים קטן (`size="sm"`).

### 4.2 Hero
- כותרת ב-3 שורות: `התאמה מדוייקת` / `תוצאות גדולות` / `FITMATCH AI`
  (השורה השלישית בגרדיאנט סגול, `dir="ltr"`).
- **הוסר** המשפט הקטן "פלטפורמת התאמה מבוססת AI" שהיה מעל הכותרת.
- פסקת תיאור.
- שני כפתורי CTA:
  - "מצא את ה־MATCH שלך" — בורר תחומים למתאמנים (`MATCH_TYPES`)
  - "אני מאמן / סטודיו" — בורר תחומים למאמנים (`TRAINER_TYPES`)
- רצועת אמון: "1,200+ התאמות בוצעו" · "6 תחומי אימון".
- שורת פילים עם שמות התחומים.
- ויזואל: אמבלם המותג המלא (`/fitmatch-icon.png`), גדול, "נשפך" אל
  תוך הפריסה בדסקטופ (`lg:-ml-[9%] lg:w-[118%]`), עם הילה רכה מאחוריו.
- שכבות הרקע הדקורטיביות עטופות ב-wrapper עם `overflow-hidden` נפרד,
  כדי שהבורר הנפתח לא ייחתך על-ידן.

### 4.3 RaceScene — ראו סעיף 6.

4 כרטיסים, אייקון + כותרת + טקסט **ממורכזים** (`items-center text-center`).

### 4.5 About
`id="about"`. `.panel` ממורכז, kicker "עלינו", כותרת עם מילה מודגשת

## 6. RaceScene — סצנת הגלילה של האיירון מן

`app/components/RaceScene.tsx` (Client Component).

### הרעיון
אנימציית מסע: מקו הזינוק ועד השגת המטרות, דרך שלבי הטריאתלון
(זינוק → שחייה → רכיבה → ריצה → סיום). התוכן מגיע מסרטון שהמייסדת
יצרה ב-AI (5 סטילס → סרטון). מתוכו חולצו **153 פריימים** ליחס 16:9,
עם עוגן חיתוך אנכי שונה לכל שלב (כדי שהמתחרה יישאר בפריים למרות
שהמקור ריבועי). הפריימים: `public/race/frames/frame_001..153.webp`
(WebP, ~4.5MB בסך הכל).

### מנגנון טכני
- הסקשן גבוה (`h-[210vh]` מובייל / `h-[420vh]` דסקטופ).
- בתוכו `<canvas>` דביק (`sticky`).
- מיקום הגלילה (0–1) בוחר את הפריים ומצייר אותו על ה-canvas
  (cover-fit עם הטיה קלה כלפי מעלה).
- כל הפריימים נטענים מראש; פס טעינה קצר עד שהשלב הראשון מוכן;
  fallback לפריים הקרוב שכבר נטען — למניעת הבהוב.
- `prefers-reduced-motion` / ללא JS → תמונת סיום סטטית + כותרת.

### תצוגה
- **דסקטופ**: וידאו במסך מלא (full-bleed) עם כותרת, כיתוב לכל שלב
  ופס התקדמות — כשכבות overlay.
- **מובייל**: מלבן ברוחב מלא (edge-to-edge) ביחס 3:2. הכותרת מעליו,
  הכיתוב ופס ההתקדמות מתחתיו (לא overlay).

### כותרת
"מלווים אותך מ**קו הזינוק** ועד השגת **המטרות שלך**" — המילים "קו הזינוק"
ו-"המטרות שלך" בצבע אדום (`#ff4d4f`, מתכתב עם האדום של IRONMAN).
בדסקטופ הכותרת בשורה אחת (`whitespace-nowrap`), במובייל נגללת.

### פס ההתקדמות
פס דק עם נקודה נעה בגרדיאנט סגול→ליים. **הכיתובים זינוק/שחייה/רכיבה/
ריצה/סיום מתחת לפס הוסרו** לבקשת המייסדת (הפס והנקודה נשארו).

## 7. נגישות

### מה נעשה בקוד
- קישור "דלג לתוכן הראשי" בראש כל עמוד (`layout.tsx`, מופיע ב-focus).
- מסגרת פוקוס גלויה (`:focus-visible`) לכל רכיב אינטראקטיבי.
- `aria-label` לשדות טופס יצירת הקשר ולכפתור הוואטסאפ הצף.
- העלאת ניגודיות הצבעים של `--muted` ו-`--faint`.
- כיבוד `prefers-reduced-motion` (אנימציות + סצנת הגלילה).
- מבנה עמוד סמנטי, `alt` לתמונות, `lang="he" dir="rtl"`.

### עמוד הצהרת נגישות
`/accessibility` — הצהרה בעברית (רמת WCAG 2.1 AA / ת"י 5568 ככל שניתן,
מגבלות ידועות, פרטי פנייה). מקושר מהפוטר.

### ווידג'ט נגישות
מחובר בקוד ב-`layout.tsx` (UserWay, דרך `next/script`, `lazyOnload`).
**רנדר רק אם** משתנה הסביבה `NEXT_PUBLIC_USERWAY_ACCOUNT` מוגדר —
כרגע לא מוגדר, אז הווידג'ט כבוי. להפעלה: הרשמה ב-userway.org, העתקת
Account ID, והגדרתו כמשתנה סביבה ב-Vercel (Production + Preview).
ניתן להחליף ב-EqualWeb/נגישות ע"י שינוי ה-script.

### מה שנותר (מחוץ לקוד)
- בדיקת נגישות ע"י **מורשה נגישות השירות** — זה מה שמאשר עמידה בתקן.
- הצהרת נגישות תקנית מלאה עם שם **רכז נגישות** ואיש קשר אחראי.
- audit מלא: ניגודיות, סדר כותרות, alt לכל תמונה, נגישות סצנת ה-canvas.

Production Branch → לשנות ל-`redesign/premium-brand` → Save.
הדומיין נשאר מקושר; מאותו רגע כל push עולה אוטומטית לאתר החי.
